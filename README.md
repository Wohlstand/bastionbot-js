# DanceBot - a successor of the BastionBot

This is the Node.JS re-implementation of BastionBot made by Hoeloe before in C#.

Later this bot was been renamed and redone into "Dance Bot", but mechanics left
the same as original Bastion Bot.

What this bot does? It's a pretty simple bot that stays at the dedicated channel
(defined in the config file), and replies with random message once user or
another bot mentioned the "dance" word in their message sent at Dance Bot's home
channel.

If mention "dance" word five times, the music clip video URL will be sent.

This bot is basically a primitive toy, or a tool to test the accessibility
through the bridge bot using third-party messengers.
